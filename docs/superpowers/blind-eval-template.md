# Creative Baseline Blind Evaluation

Use one independent form for each `evaluation_context_id`. The evaluator must not be told which version is `baseline_v0` or `baseline_v1` until both forms are complete.

| Dimension | Rating | Evidence timestamp(s) | Concrete issue or reason |
| --- | --- | --- | --- |
| First 3 seconds | `low` / `ordinary` / `high` | | |
| Script coherence | `low` / `ordinary` / `high` | | |
| Visual consistency | `low` / `ordinary` / `high` | | |
| Highlights | `low` / `ordinary` / `high` | | |
| Viewing experience | `low` / `ordinary` / `high` | | |

Record the `evaluation_context_id`, `video_version_id`, evaluator, completion time, and every evidence timestamp with this form. Do not use a total score. The comparison tool applies the fixed pass rule after both forms are complete.
